# Targeting history

This repository has been retargeted twice. Keep this record so the measurement
identity is not confused with the coding agent that built the harness.

1. The first implementation treated **Grok 4.6 / xAI** as the only target and
   required `XAI_API_KEY`.
2. A later in-place refactor treated **GPT-5.6 Sol on Codex** as the only
   target and removed production xAI paths.
3. The current scientific contract is the dual-model experiment in the
   uploaded research report: **Grok 4.6 and GPT-6 Astra**, four shared
   efforts, `model_only` and `agentic` tracks, Responses-style APIs.

The coding agent that implements this repository is not a model under test.

Codex / `gpt-5.6-sol` remains an optional unblended product series. It must
never be mixed into Grok or Astra statistics.
